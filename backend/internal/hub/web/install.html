Install the controller

The controller is one container. It serves the dashboard, adopts your machines, and manages the AI module. Local-first: it needs nothing from us to run.

1 · Run the controller

On the machine that will lead your mesh (any Docker host):

curl -fsSL https://traego.ai/install.sh | sh -s -- controller

It generates your admin key and join token, prints them once, and serves the dashboard at http://<that-machine>:8443 — plain HTTP on your LAN by default, TLS and Let's Encrypt when you want them.

2 · Join your machines

On every other box, paste the join command the controller printed:

curl -fsSL https://traego.ai/install.sh | sh -s -- join \ --controller http://<controller>:8443 --token <JOIN_TOKEN>

Each machine prints a pairing code and appears in your dashboard waiting to be adopted. Confirm the code, pick a role, done — it heartbeats over mTLS from then on.

3 · Optional: install the AI module

One click in the dashboard. Traego starts and manages the inference backend itself, and your model catalog fills in — sized to the memory your machines actually have.
